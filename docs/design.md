# Design notes

The visual direction is an editorial engineering journal: warm paper, evergreen ink, large type and an original system schematic. The case study carries the detail; the homepage offers a short introduction and a clear route into the evidence.

Motion is progressive enhancement. Fine-pointer desktop devices get restrained depth on the hero illustration; scrolling reveals sections and updates a reading-progress indicator. Touch layouts remain direct, reduced-motion preferences disable spatial effects, and all primary content remains available without JavaScript. There is no scroll hijacking.

Reference research included [Codrops' examination of Eduard Bodak's portfolio](https://tympanus.net/codrops/2025/07/29/built-to-move-a-closer-look-at-the-animations-behind-eduard-bodaks-portfolio/) and [Motion's scroll documentation](https://motion.dev/docs/scroll). The implementation and SVG were prepared for this project. No third-party template, animation library or reference-site code is included.
