# Practice sequence

Keep each first prediction. Use a new run folder for each attempt.

1. Trace each guided request. Check both the action and resource fields.
2. Mark the matching start of the resource name and circle the action. If nothing matches, which field would you check next?
3. Try the changed case. Save a decision and matching record IDs for each request before checking. Explain how you reached each answer.
4. Try the challenge case without reference files. Save each result and its matching statement IDs. Then ask someone to review your reasons.
5. Teach a partner how a matching deny differs from a missing allow.
6. Two days later, make a new object request on a fresh copy. Predict the result on paper before running analyse.
