# Practice stages

1. Guided: prepare `guided`, write the prediction first, then run it. Keep
   the first notes and compare with WORKED-EXAMPLE.md only afterwards.
2. Prompts: Which value identifies the visit, and which value must the intended form return? Does a 403 alone prove state stayed unchanged?
3. Independent: Use `challenge`. Track which visit each token belongs to and predict each state read before opening the reference.
4. Changed: Use `changed`. Read each form request and predict its result. Run the matching browser forms as a separate check.
5. Teach-back: Explain how a browser can send a form across origins yet limit what the sending page can read back.
6. Later recall: next week, use a new attempt folder. Draw the two ports, session cookie and form token. Mark what the script supplies. What must the browser check show?

Label notes `first attempt`, `revised after evidence` or `later recall`.
These labels show the stage. They do not prove skill. Keep what you saw
apart from what you first thought would happen. Ask someone to review your
reasons and what you still need to check.
