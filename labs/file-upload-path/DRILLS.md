# Practice stages

1. Guided: prepare `guided`, write the prediction first, then run it. Keep
   the first notes and compare with WORKED-EXAMPLE.md only afterwards.
2. Prompts: Can a Content-Type header prove the file format? Why generate a storage name even after checking the submitted name?
3. Independent: Use `challenge`. Predict how the byte limits and rules for system names apply. Then check the write and readback evidence. Keep the reference closed until then.
4. Changed: Use `changed`. Compare the content with its claimed format. In a fresh copy send a valid one-pixel image with another allowed colour value.
5. Teach-back: Explain the difference between checking a filename and proving where a file was actually saved.
6. Later recall: next week, use a new attempt folder. Predict one accepted upload and one name that looks like a path. Then explain the file evidence. Which files should cleanup remove?

Label notes `first attempt`, `revised after evidence` or `later recall`.
These labels show the stage. They do not prove skill. Keep what you saw
apart from what you first thought would happen. Ask someone to review your
reasons and what you still need to check.
