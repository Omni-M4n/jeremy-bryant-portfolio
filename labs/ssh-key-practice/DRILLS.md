# Practice and recall

1. Guided: decide what each trial and recovery test shows. Then read the example.
2. With prompts: in a fresh run copy, change only the host fingerprint match to
   false. Predict the labels again. Which evidence supports your choice?
3. Independent: prepare `challenge`; keep its reference closed. Explain each
   login result. Then explain what the recovery test shows.
4. Changed case: prepare `changed`. What does each trial prove? Name any extra
   evidence you need before you can claim that a key worked or was rejected.
5. VM practice: follow the two-VM steps only in new disposable guests. Keep public
   fingerprints and proof of the login method. Never put private keys in a report.
6. Teach back: what does a local key passphrase do? What does a server account
   password do? What does a server host fingerprint show? Use one sentence each.
7. Later recall: in two days, explain what a timeout can tell you about key rules.
   What recovery test must you run before you change how users log in?

Hand over first attempts, the method used and why each failed login failed.
Include recovery notes, limits and help used. A reviewer checks each claim.
