# Practice progression: Review MFA and recovery controls by account type

Use the prepare, show and check commands in [README.md](README.md). Save a prediction before you run `analyse`. Use fresh folders to keep earlier attempts.

1. **Guided (10 minutes):** inspect each guided account and its type. Predict the labels in policy order. Explain the difference between setting up a method and requiring it at sign-in.
2. **With prompts (5 minutes):** does recovery give a weaker way in? Who owns the software account? Can its password still be used? Which emergency rules still apply during an exception?
3. **Independent (10 minutes):** prepare `challenge` in a fresh folder. Apply the sign-in and recovery rules for each account type. Cite evidence for each decision. State which controls have not been tested. Save your answers, evidence and a short handover first. Then open `analyse`, the reference answers or worked example. Record any help used.
4. **Changed evidence (5 minutes):** prepare `changed`. Compare the review date, exception date and test age with the rules. In a practice copy, set the test age to 90. Predict the full result before you check it. Explain any result that stays the same or changes.
5. **Teach back (5 minutes):** explain what the words "MFA enrolled" do and do not prove. Explain why an account's service label does not settle whether it is safe.
6. **Later recall (next day, 5 minutes):** list the four service rules and five emergency rules without the reference. State the rule for an exception's end date.

For each pass, record your decision and reason. Cite the evidence. State what is unclear, any help used and one next check. If you can, ask someone to review your words and a new case. Until then, your skill at doing this alone is unassessed, even if all labels match. Keep all attempts below `run/`.
