# Drills: Linux mode bits and directory traversal

## Guided practice

Prepare guided in a fresh run folder. Read the README rules. Predict a result for each decision ID and save it. Then read WORKED-EXAMPLE.md. Put any correction in a new paragraph. Keep your first reasons visible.

## Prompts only

Close the worked example and think about these questions:

- Why can other=6 fail to help the owner of a file with owner=0?
- How does execute access for a folder differ from execute access for a file?

## Independent attempt

Prepare challenge in a fresh folder. Save answers.json and a five-sentence handover in notes.txt before you open any answers. Until then, keep reference outputs, the worked example and analyse closed.

In the handover, state what you saw and what you think it means. Give one other possible explanation. Add what is unclear and your next check. You may use the README for syntax. Record that help. Then run analyse and check. Ask a person to review your reasons. Your skill at doing this alone is unassessed until someone reviews it.

## Changed case

Prepare changed. Predict each result before you check it. Compare the actor and node fields with the guided case. For each request, record which class you select and why. Explain any results that stay the same or change.

For a small edit drill, copy the guided case. Change /srv mode from 750 to 740 in that copy. Predict every request's result before you run the tool. Do not run chmod on a real file.

## Teach-back

Explain each ancestor search check and the chosen target bits for a file read. Then explain the difference between listing names and finding a known filename. Use exact record IDs from your attempt. Ask a partner for a case that tests your rule. Record the question and your answer.

## Later recall

After 24-72 hours, open only your own notes and a fresh case. Write the main rule from memory. Name one edge case or gap in the evidence. Predict the result. Then check the guide and note what you forgot. Reading an answer again does not count as an attempt on your own.

## Handover

Keep the copied case, filled worksheet and notes together. State the scope and conclusion. Add two evidence references, any unresolved doubt and the next check you want. Record help used and whether someone assessed your reasons. Do not claim experience beyond this made-up exercise.
