# Shell practice sequence

1. **Guided.** Prepare `guided` in a fresh run folder. For each ID, write the question before the decision. Predict what the exit status means. Work out the spare bytes yourself. Save the first attempt, then open the worked example. Keep corrections visible.
2. **Prompts only.** Close the solution. Explain the difference between one argument with spaces and several path arguments. When can `$?`, `$LASTEXITCODE` and Bash pipeline status mislead? Think about recording them too late or using the wrong program's rules.
3. **Independent.** Prepare `challenge` in a different run folder. Use only its records, the README's rules and local command help. Explain each result, what is still unknown and the smallest next query. Keep its answer file closed. Do not run `analyse` or read the code before saving your answer. This drill gives no answer labels.
4. **Changed case.** Prepare `changed`. Use the rules for its stated shell. Check the location, current command result and space budget. Compare the expected process with the one shown. What further evidence would settle an open service or socket question? Save before checking.
5. **Live notebook.** Complete one README task in an already prepared disposable VM. Save a successful read, empty search and missing-file error. Add your own process, one file-system result, one service query and one local-port query. Explain unexpected results. Do not change the system to fit them. Record missing tools or denied access.
6. **Teach-back.** Ask a reviewer to point to one output field. Ask, “What does this show?” Then ask, “What would you check next?” A name, nonzero code, stopped service or wildcard listener alone does not prove a break-in. Correct any such claim.
7. **Recall.** Next day, choose commands for three questions without notes. Explain their limits. About a week later, use a fresh fixture copy. Change its working folder or make its free space exactly meet the budget. Predict first, check later and keep the earlier attempt.

Record the stage: guided, prompted, independent attempt, reviewer checked, or recall attempted. Having the materials and matching labels does not show that you can do the work alone.
