# Practice sequence

1. **Guided, 25-35 minutes.** Prepare `guided`. Predict each task's owner and
   evidence state using the agreement and checks. Save a first worksheet, then
   read the worked example. Preserve corrections beside the first attempt.
2. **Prompted.** For every row ask: which component, which action, which agreement
   sentence, which check, and what evidence is still absent? Identify a control
   whose responsibility and evidence tell different parts of the story.
3. **Independent, 20 minutes.** Prepare `challenge` in `run/independent-01`.
   Close the worked example, reference folder and analysis command. Complete the
   matrix, write the next evidence request and identify what cannot be allocated
   from the supplied agreement. Save before checking; log help used.
4. **Changed case, 20 minutes.** Prepare `changed` in `run/changed-01`. Explain
   what migration changed and what work remains with the customer. Compare two
   exact evidence references with your earlier attempt. Do not assume a backup
   promise demonstrates usable restored content.
5. **Boundary experiment.** In a new copy of a case, change one evidence state
   while keeping its owner claim fixed. Predict which part of the decision will
   change. Then try an unsupported service model and record the rejection.
   Keep source fixtures unchanged.
6. **Teach-back.** Explain to a reviewer why a broad phrase like shared security
   needs named tasks and evidence. Have them ask for a counterexample to one of
   your claims and record any correction.
7. **Later recall.** Tomorrow, reconstruct the task split from memory before
   reopening your notes. In about a week, have a reviewer change a service model
   and one agreement detail in a fresh copy; repeat without the solution.

Record stage, date, evidence, help and corrections. A script match is a material
check; an unfamiliar case and an assessed explanation show what you can do.
