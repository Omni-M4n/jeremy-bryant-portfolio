# Practice sequence

1. **Guided, 25-35 minutes.** Prepare `guided`. Use the agreement and checks to
   predict each task's owner and evidence state. Save a first worksheet, then
   read the worked example. Keep corrections beside the first attempt.
2. **Prompted.** For each row, name the part of the service and the action.
   Which agreement sentence sets the owner? Which check gives evidence? What is
   still missing? Find a control where the owner and result tell different parts
   of the story.
3. **Independent, 20 minutes.** Prepare `challenge` in `run/independent-01`.
   Close the worked example, reference folder and analysis command. Complete the
   table. Write the next evidence request. Which tasks cannot be assigned from
   the given agreement? Save before checking and log help used.
4. **Changed case, 20 minutes.** Prepare `changed` in `run/changed-01`. Which
   tasks changed when the team moved services? Which still belong to the
   customer? Compare two exact evidence references with your earlier attempt.
   Check what each backup record actually shows.
5. **Boundary experiment.** In a new case copy, change one evidence state.
   Keep its owner claim fixed. Predict which part of the decision will change.
   Then try a service model the helper does not support. Record the rejection.
   Keep source fixtures unchanged.
6. **Teach-back.** Explain why a broad phrase like shared security needs named
   tasks and evidence. Ask a reviewer for a case that would challenge one of
   your claims. Record any correction.
7. **Later recall.** Tomorrow, write the task split from memory before opening
   your notes. In about a week, ask a reviewer to change a service model and one
   agreement detail in a fresh copy. Repeat with the solution closed.

Record stage, date, evidence, help and corrections. A script match checks the
materials. A new case and a reviewed explanation give evidence of what you can do.
