# Practice sequence

1. Predict the guided records, then do each step in the local service. Keep the first event log with its secrets removed.
2. Ask whether the account was enrolled and the password was right. Did the proof match, and had it been accepted before?
3. Try the changed worksheet. Save each decision and the fields used before checking. Explain how those fields lead to your answer.
4. Try the challenge worksheet without references. Save predictions and evidence before checking. Each record is a separate sample.
5. On a fresh local account, make a code at 59 and try to confirm it at 60. Record what happens at the time boundary. Two six-digit codes can sometimes be the same. This test cannot prove that every code is unique. The automated boundary test uses a fixed RFC seed.
6. Teach why successful recovery replaces the training seed and clears sessions. Explain why you must enrol again. Name one weakness the local service still has.
7. Later, draw the stages from memory. Which records would you need to check another person's recovery claim?
