# Practice sequence

Use the README's decision labels before each reveal. Save your own words first,
then put them into the exact helper format. Keep a note of any help.

1. **Guided:** Prepare `guided` as `attempt-01`. Read the evidence and fill `redaction-template.md`. Save the first draft before the worked example.
2. **Prompts:** Could a rare time reveal a person after a name is removed? What belongs in the private mapping? What links between values must the copy retain? Does every event support the claim? Record help before you revise.
3. **Unfamiliar practice:** Close the worked example and reference folders. Run `python lab.py prepare --scenario challenge --out run/attempt-02`. Make a new draft from that packet. Save it before feedback. Ask a reviewer to read your reasons before the reveal. These shipped cases are practice. An independent assessment needs a fresh case made by a reviewer.
4. **Changed case:** Run `python lab.py prepare --scenario changed --out run/attempt-03`. Use a new draft. Compare the facts and state which claims still hold, which need revision and which need more evidence. Do not change the first attempt to make it look right.
5. **Teach-back:** Explain the task to a beginner with an everyday example. Name one thing the evidence supports and one thing it cannot prove.
6. **Later recall:** After 2-7 days, explain the method without the guide. Record the date, errors, help and one practice need. Leave the result blank until you try it. The helper does not assess mastery.

For each fresh redaction attempt, save a plan before running the copy command.
Read the whole excerpt after the run. Where there are two events, assess the
claim against both. Cite the event and result for each. Check whether same
and different values remain distinct. Explain any lost link or remaining
private clue. The two fixed helper labels cannot do this review for you.
