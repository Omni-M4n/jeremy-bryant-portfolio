# Drills: TCP handshake investigation

## 1. Guided evidence pass

Prepare guided as `run/attempt-01`. Keep WORKED-EXAMPLE closed at first. Read the question. Mark what is in scope and where the evidence comes from. Fill each decision and give a short reason. Use the word list if needed, and note that help. Allow 35-45 minutes for this first pass.

## 2. Fewer prompts

Answer these questions before you open the analysis:

- Which side sent each set of flags?
- What number should each ACK confirm after one SYN?
- What evidence tells a reset from no visible response?

Check your choices and read the worked example. Write one correction and cite the evidence for it. If all labels matched, explain your hardest choice. A lucky guess does not show that you understood the rule.

## 3. Independent case

Prepare challenge in a fresh folder. Choose a label for each connection from its packets. Cite the records that support your choice. Explain where the capture limits what you can say. Keep the set answers, worked example and analyse closed for now. First save your choices, source notes and handover. Use the README for terms or syntax if needed, and note that help. Then compare the results. Ask another person to assess your reasons. A label that matches does not show what you understood.

## 4. Changed conditions

Prepare changed in a separate folder. Compare its evidence with guided and keep both attempts. Save your first choice for each result before you view the analysis.

- Which opening packets are present for each flow?
- Do the sequence and ACK numbers match what the rules expect?
- What would you ask about where and when the capture was taken?

State which fact changed. Explain why the rule gives the same or a new result. State what is still unknown. Do not edit the supplied cases or set answers to make your choice match.

## 5. Teach-back

Explain why three correctly named flags are not enough. Show how to work out the two expected next numbers. State one thing the capture leaves unknown. Cite one record ID. Give one example where the rule would give a different result. If you need the worked example, note that help. Try again later with it closed.

## 6. Later recall

Two days later, sketch the usual three-packet opening. Use new numbers 70 and 500. Write both ACK values. Then list what an absent response does not prove. Record the date. State what you recalled on your own and what you had to check. Add one question you still have. This records your practice. It does not prove full skill in real work.

## Handover

Keep your own saved worksheet and a short handover note. Answer: "What did I see? Where is the evidence? What is unknown? What should be checked next?" Include your first choices, corrections and help used. This lab does not ask you to upload or publish anything.
