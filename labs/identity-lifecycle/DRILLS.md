# Practice progression: Reconcile joiner, mover and leaver access

Use the exact prepare/show/check commands in [README.md](README.md). Save a
prediction before running `analyse`. Fresh folders preserve earlier attempts.

1. **Guided (10 minutes):** draw current, required and exception sets for all
   guided records. Save your deltas before opening the worked example.
2. **With prompts (5 minutes):** Is the event effective yet? Does each exception
   name old access? Does it expire today or before today? Which access must stay?
3. **Independent (10 minutes):** use `challenge`. Preserve `future-mover`'s
   present duties, remove `late-leaver` access, and finish `partial-mover`'s new
   duties without deleting the new queue already granted.
4. **Changed evidence (5 minutes):** use `changed`. Explain why the same
   `old-reports` exception no longer applies. Why is early joiner access removed
   while future leaver access remains? In a practice copy move `as_of` to
   `2026-10-25` and predict both changes before running the analysis.
5. **Teach back (5 minutes):** explain why a mover review needs both additions
   and removals. Identify two offboarding tasks outside this entitlement model.
6. **Later recall (next day, 5 minutes):** write the three set formulas and the
   expiry boundary without notes. Rebuild the team-move delta from the fixture.

For each pass record: evidence references, decision, reason, uncertainty, help
used and one next check. Have another person review the explanation and one
unfamiliar case if possible. Until that occurs, independent completion is
unassessed even if every decision matches. Keep all attempts below `run/`.
