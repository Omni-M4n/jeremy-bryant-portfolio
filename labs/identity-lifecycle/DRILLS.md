# Practice progression: Reconcile joiner, mover and leaver access

Use the prepare, show and check commands in [README.md](README.md). Save a prediction before you run `analyse`. Use fresh folders to keep earlier attempts.

1. **Guided (10 minutes):** draw the current, required and exception sets for each guided record. Save the access changes before you open the worked example.
2. **With prompts (5 minutes):** is the event due yet? Does each exception name old access? Does it expire today or before today? Which access must stay?
3. **Independent (10 minutes):** prepare `challenge` in a fresh folder. Work out each person's target access at the review date. Record what to add, remove and keep, with reasons. Save your answers, evidence and a short handover first. Then open `analyse`, the reference answers or worked example. Record any help used.
4. **Changed evidence (5 minutes):** prepare `changed`. Compare each event date and exception date with `as_of`. Record each person's target access and your reasons. In a practice copy, move `as_of` to `2026-10-25`. Predict each result before you check it.
5. **Teach back (5 minutes):** explain why a move needs checks for both added and removed access. Name two tasks for a staff departure that this model leaves out.
6. **Later recall (next day, 5 minutes):** write the three set formulas and the expiry rule without notes. Work out the team-move changes from the supplied case again.

For each pass, record your decision and reason. Cite the evidence. State what is unclear, any help used and one next check. If you can, ask someone to review your words and a new case. Until then, your skill at doing this alone is unassessed, even if all labels match. Keep all attempts below `run/`.
