# Practice stages

1. Guided: prepare `guided`, write the prediction first, then run it. Keep
   the first notes and compare with WORKED-EXAMPLE.md only afterwards.
2. Prompts: Where do the SQL quotes end in the joined route? Does a 200 response always mean one reader matched?
3. Independent: Use `challenge`. Predict both row lists. Explain what the response shows about each route. What does it leave untested?
4. Changed: Use `changed`. Predict what each route does with an apostrophe in a real name. Then make a new copy with the supplied ordinary name `Mira`.
5. Teach-back: Explain the difference between a name value and an instruction without saying that all punctuation is bad.
6. Later recall: next week, use a new attempt folder. Explain why an empty result and a failed query tell you different things.

Label notes `first attempt`, `revised after evidence` or `later recall`.
These labels show the stage. They do not prove skill. Keep what you saw
apart from what you first thought would happen. Ask someone to review your
reasons and what you still need to check.
