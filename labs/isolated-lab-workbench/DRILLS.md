# Workbench practice sequence

1. **Guided, 15-25 minutes.** Prepare `guided` in a new `run/attempt-01`. Predict all six decisions. Sketch the boundary and cite a record for each claim. Save before opening the worked example. Keep corrections beside your first answer.
2. **Prompts only, 10 minutes.** Close the solution. Explain why each check alone is not enough: a successful loopback request, no default route, or a screenshot of one disabled adapter. Where must you keep evidence before a restore? Why?
3. **Independent, 15 minutes.** Prepare `challenge` in a fresh folder with `--scenario challenge`. Read the packet and answer its question. Cite each record you used and explain what it shows. Choose a next check only if needed. Keep `reference/challenge.json` closed. Do not run `analyse` or read the code until you save your worksheet and diagram. Record help used and doubts. This drill gives no answer key.
4. **Changed case, 15 minutes.** Prepare `changed` with the worked example closed. Check each adapter and host channel against the stated boundary. Separate proof of a connection from proof of a restore. Explain the next review step. Do not contact another machine or change host settings. Then check and keep any differences.
5. **Hands-on, 30-45 minutes if prepared.** Follow the README only in the separately made disposable VM. Keep its identity, settings, routes, both loopback results and three hashes. If the VM is unavailable, record “supplied-evidence practice only; real workflow not performed.”
6. **Teach-back.** Ask a reviewer to choose one screenshot or output line at a time. Explain what it can and cannot show. What would change if a second adapter or shared folder appeared? Show how to select a restore. Do not use an original coursework VM.
7. **Later recall.** Next day, draw the boundary without notes. Put the baseline, change and restore records in order. About a week later, review a fresh case copy with one adapter slot or hash missing. Predict what you can still claim before checking. Do not overwrite the earlier attempt.

Record the stage: guided, prompted, independent attempt, reviewer checked, or recall attempted. Having the files and matching the labels does not prove that you have done the hands-on work or mastered it.
