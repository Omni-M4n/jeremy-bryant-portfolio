# Workbench practice sequence

1. **Guided, 15-25 minutes.** Prepare `guided` in a new `run/attempt-01`. Predict all six decisions, sketch the boundary and cite a record for each claim. Save before opening the worked example. Preserve corrections next to the original explanation.
2. **Prompts only, 10 minutes.** Close the solution. Explain why one successful loopback request, an absent default route, and one disabled adapter screenshot are each incomplete by themselves. Identify where pre-restore evidence must be kept and why.
3. **Independent, 15 minutes.** Prepare `challenge` in a fresh folder with `--scenario challenge`. Read the packet and answer its question. Cite the records you used and explain what each one shows. Choose a next check only if your answer needs one. Do not open `reference/challenge.json`, run `analyse`, or inspect the implementation until your worksheet and diagram are saved. Record help used and uncertainty; no answer key is printed here.
4. **Changed case, 15 minutes.** Prepare `changed` with the worked example closed. Compare the specified boundary to every adapter and host channel. Separate connectivity evidence from rollback evidence. Explain the next review action without contacting another machine or changing host settings. Then check and preserve the differences.
5. **Hands-on, 30-45 minutes if prepared.** Follow the README only inside the separately created disposable VM. Retain identity, settings, route evidence, positive/negative loopback results and three hashes. If unavailable, explicitly record “supplied-evidence practice only; real workflow not performed.”
6. **Teach-back.** Have a reviewer select one screenshot or transcript line at a time. Explain what it supports, what it does not, and what would change if a second adapter or shared folder appeared. Demonstrate restore selection without operating on an original coursework VM.
7. **Later recall.** Next day, draw the boundary and order the baseline/change/restore observations without notes. About a week later, review a fresh copy of a case with one adapter slot omitted or one hash missing. Predict the limited conclusion before checking. Do not overwrite the earlier attempt.

Record stage as guided, prompted, independent attempt, reviewer checked, or recall attempted. Prepared materials and decision matches are not personal completion or mastery evidence.
