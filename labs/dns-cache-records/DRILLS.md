# Practice sequence

1. **Guided, 10 minutes:** prepare `guided`. Draw the name path for each query. Save a first answer before opening the worked example. Find the address records and the mail record.
2. **Prompts, 5 minutes:** Which clock starts a TTL? Does a source edit rewrite a saved TTL? Does an MX result prove that mail was delivered? Record evidence for each answer.
3. **Challenge, 10 minutes:** prepare `challenge` into `run/attempt-02`. Keep `analyse`, worked examples and reference files closed. Work out each query's expiry. Decide what the cache can supply. Explain what the evidence does not show.
4. **Changed case, 10 minutes:** prepare `changed` into a fresh folder. Predict each answer before you work it out. In a second copy, move one query by one second across an expiry. Keep both attempts and explain any change.
5. **Teach-back:** use a paper address book to explain aliases and saved answers to someone new to DNS. Explain why a missing record type differs from a missing name.
6. **Later recall, two days later:** without notes, write how to find positive and negative expiry times. Then check your notes. Record one correction, help used and one point still unclear.

Handover: share a query timeline, record map and first attempts. Ask a reviewer to challenge one claim. A matching worksheet shows one stage of practice. It does not prove that you can do the task on your own.
