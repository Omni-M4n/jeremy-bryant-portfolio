# Practice progression: Build a cloud audit evidence timeline

Use the exact prepare/show/check commands in [README.md](README.md). Save a
prediction before running `analyse`. Fresh folders preserve earlier attempts.

1. **Guided (10 minutes):** make a timeline with ID, identity, session, action,
   result and possible sign-in link. Predict labels before the worked example.
2. **With prompts (5 minutes):** Is the result success? Is identity as well as
   session equal? How many minutes elapsed? Does approval match the resource?
3. **Independent (10 minutes):** prepare `challenge` in a fresh folder.
   Build the event timeline and evaluate each possible correlation using the stated identity, resource and time rules. Explain uncertain relationships.
   Save decisions, evidence references and a short handover before opening
   `analyse`, reference answers or the worked example. Record any help used.
4. **Changed evidence (5 minutes):** use `changed`. Why does denied logging
   disablement leave `coverage-configured`? In a copy change only `c03.result`
   to `success` and predict both its event decision and the logging suffix.
5. **Teach back (5 minutes):** explain why successful sign-in, successful object
   read, and proof of a particular person's action are three different claims.
6. **Later recall (next day, 5 minutes):** reconstruct the correlation rule and
   state what an absent record can and cannot establish with incomplete logs.

For each pass record: evidence references, decision, reason, uncertainty, help
used and one next check. Have another person review the explanation and one
unfamiliar case if possible. Until that occurs, independent completion is
unassessed even if every decision matches. Keep all attempts below `run/`.
