# Practice ladder

1. **Guided, 10 minutes.** Prepare guided as attempt-01. Read README.md, inspect
   every record, and save a first prediction. Then do the practical commands,
   if supplied. Open WORKED-EXAMPLE.md only after that first attempt.
2. **With prompts, 10 minutes.** Trace the loop once for each guided line. Explain when a line can change the count.
3. **Independent, 15 minutes.** Prepare challenge as attempt-03. Keep the worked
   example and reference folder closed. Read every input. Predict each decision,
   cite IDs, and save the expected output before running analyse. Write down any help.
4. **Changed case, 10 minutes.** Prepare changed as attempt-02. Apply the input, repeat, time and outcome checks to each line before looking at any output.
   Explain which evidence changed your reasoning. Change one field in a new copy,
   predict the effect, and check it. Do not overwrite your first attempt.
5. **Teach back, 3 minutes.** Explain the half-open window using a class period that ends when the next begins. Use an everyday example, then a record ID.
6. **Later recall, 10 minutes.** After two days, use a fresh folder. Explain the
   rules without opening the answer. Do one small calculation by hand. Check it,
   mark any help, and list what you still need to practise.

Journal: prediction; command; actual evidence; interpretation; uncertainty;
next evidence; help; later recall. A label match is not an assessment of skill.
