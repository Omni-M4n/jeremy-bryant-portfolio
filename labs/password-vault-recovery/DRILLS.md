# Practice sequence

1. Predict the guided worksheet, then run the dummy-file commands. Keep your first answer and the check result with secrets removed.
2. Ask whether the copy exists, whether it opens and what unlocks it. Could losing one place remove every copy?
3. Try the changed case on a fresh copy. Save each decision, your reasons and the fields you used before checking.
4. Try the challenge case without the worked example or reference folder. Save all decisions and the exact fields that support them before checking.
5. If KeePass 2 is already on your computer, complete Part B with fake entries. Otherwise, mark the app steps as not run. Do not install software.
6. Teach why copying a file and proving recovery works are different. Explain why the supplied plaintext store is unsafe for real passwords.
7. Later, draw the recovery plan from memory. Name what must be kept apart. State which evidence you would collect while keeping all secrets out.

Label the stage of your work. Was it a first try, done with prompts, checked
on your own, or recalled later? A matching answer alone does not prove that
you have learnt the skill. Keep first attempts and reviewer feedback.
