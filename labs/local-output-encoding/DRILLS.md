# Practice stages

1. Guided: prepare `guided`, write the prediction first, then run it. Keep
   the first notes and compare with WORKED-EXAMPLE.md only afterwards.
2. Prompts: How do the response source and the text you see differ? Why must you name where the output appears?
3. Independent: Use `challenge`. Predict all three displays and their response types before opening a browser or a reference.
4. Changed: Use `changed`. Track the ampersand from raw input to response source to the text you see. In a fresh copy use `hello` to check normal text.
5. Teach-back: Explain why making markup show as text in a paragraph differs from allowing some tags to change its style.
6. Later recall: next week, use a new attempt folder. Draw the path from the first marker to response bytes to the text you see. State which stage each saved record proves.

Label notes `first attempt`, `revised after evidence` or `later recall`.
These labels show the stage. They do not prove skill. Keep what you saw
apart from what you first thought would happen. Ask someone to review your
reasons and what you still need to check.
