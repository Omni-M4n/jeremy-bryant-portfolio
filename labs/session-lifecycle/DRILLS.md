# Practice stages

1. Guided: prepare `guided`; predict all six requests before running. Keep
   your first notes. Then compare the worked example with actual evidence.
2. Prompts: which state lives on the client? Which state lives on the server?
   What does replay test that watching the login page does not?
3. Independent: prepare `challenge` in a fresh folder. Predict which cookie
   each profile step uses and what a wrong login changes. Run it, explain
   every status, and only then open its reference.
4. Changed: prepare `changed`. Mark the request either side of the wait.
   Use elapsed times to explain the boundary. In another fresh copy move the
   wait earlier; predict before running. Keep the plan to eight steps or fewer.
5. Teach-back: explain why a pass can remain visible in a client but no longer
   work. Include normal login after logout and after expiry.
6. Later recall: next week, use a new folder. Predict the logout replay and
   expiry results without opening the worked example. Compare reasons, not
   just response numbers.

Label notes `first attempt`, `revised after evidence` or `later recall`.
No stage label is a claim of mastery. A peer should check the explanation.
