# Practice: check a backup

## Start with help

Prepare guided in a new run folder. Read the README rules and use the payload inspector. Predict each decision from your measurements. Save your answer before opening WORKED-EXAMPLE.md. Add any correction in a new paragraph. Keep your first answer.

## Use prompts

Close the worked example. Try these questions:

- What does a matching hash show? What does it leave untested?
- Can a complete copy with matching bytes still fail the RPO check? Explain why.

## Try without the answer

Prepare challenge in a new folder. Use the inspector to measure the dummy files. Keep reference answers, the worked example and analyse output closed. Save answers.json and a short note in notes.txt. Give a fact, your interpretation, another possible explanation, a limit and a next check.

Use the README for syntax if needed. Record that help. Then run analyse and check. Ask someone to review your evidence and explanation. Until then, the attempt has not been independently assessed. A case you have already read is repeat practice, not an unseen test.

## Change the evidence

Prepare changed. Measure the payloads and compare every copy with all the rules.

- Which measured hashes match the expected values? Which, if any, differ?
- Does each copy meet the file, retention and age rules? Show the facts for each check.

For a small edit, use a copy of guided. Set b1 captured_at to 2026-02-01T08:00:00Z. Work out its age and predict the result. Then try 07:59:59Z in a separate copy. Explain each result before analysis. Keep the original files intact.

## Teach it back

Explain file scope, age, retention, matching bytes and app use as separate checks. Show why RPO and RTO answer different questions. Cite exact IDs from your case. Ask a partner to change one fact and challenge your answer. Save the question and your reply.

## Recall it later

After 24–72 hours, use your notes and a fresh case. Write the main rule from memory. Name one boundary or missing fact that could matter. Predict a result before checking the rules. Record what you forgot. Rereading an answer is not a fresh attempt.

## Hand it over

Keep the case, worksheet and notes together. State the scope, conclusion, two evidence references, one limit and a next check. Include help used and whether someone reviewed your reasoning. Describe only the practice you actually did.
