# Guided worked example

Read this after saving your first attempt. This is a fictional example, not a
claim that a learner or an author ran a real engagement.

Guided item-1 has a DNS answer but no HTTP observation. It supports only name resolution. Item-2 checks one of two accounts; even a complete count would not prove each permission correct. Write the narrower claim and next check in your bundle. The shipped cases rehearse the process. An independent attempt needs fresh evidence and a reviewer who has not coached your answer.

Expected guided decision strings:

```json
{
  "item-1": "supported-within-case",
  "item-2": "collect-bounded-evidence"
}
```

Keep the first attempt. Write corrections in a separate file, explaining which
fact changed your answer. A useful explanation names the evidence and its limit.
