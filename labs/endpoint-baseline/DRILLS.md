# Practice and recall

1. Guided: calculate each observation's age and compare its value before opening
   the worked example. Keep the first attempt.
2. With prompts: in a fresh run copy, set the observed lock time to exactly 300,
   then 301 seconds. Predict each result. What does observed 0 mean here?
3. Independent: prepare `challenge`; keep the references closed. Check evidence
   age before exceptions. Explain each expiry date against the review date.
4. Changed case: prepare `changed`. Check the date and value for each control.
   Choose the next action for each. Keep the normal-use result separate.
5. VM practice: collect the four controls in a new guest and make the bounded
   lock change. Save the actual timing and normal note-edit test.
6. Teach back: explain why a reason for an exception needs an owner and an expiry.
   Why can that exception not supply a missing observation?
7. Later recall: in two days, name the four controls and one useful job to test
   after changing a lock setting. Explain one limit of the baseline.

Hand over first answers, evidence dates, test results, proposed versus approved
exceptions, limits and help used. A reviewer checks the evidence and reasoning.
