# Practice and recall

1. Guided: compare each field before opening the example.
2. With prompts: in a fresh run copy, remove the approval for `e2`. Do not change
   the observed entry. Predict the new label and explain which fact is missing.
3. Independent: prepare `challenge`; keep references closed. Check every ID in
   either snapshot. Include records that appear in only one of them.
4. Changed case: prepare `changed`. Compare each field for each entry. Which facts
   support your choices? Would a check of the file name alone be enough?
5. VM practice: record a real sign-in note from the README's disposable VM.
   Preserve the launch file hash and the observed note as separate evidence.
6. Teach back: explain why a service, Startup file and Run key need different
   collection commands, even when each starts a program.
7. Later recall: in two days, name five fields to compare and one reason not to
   delete an unexplained entry immediately.

Hand over first attempts, field comparisons, bounded VM evidence, help used and
one collection gap. A reviewer checks the reasons and scope.
