# Practice stages

1. Guided: prepare `guided`, write the prediction first, then run it. Keep
   the first notes and compare with WORKED-EXAMPLE.md only afterwards.
2. Prompts: Which part of the URL is sent as the target? What tells the server how to read a POST body?
3. Independent: Use `challenge`. Predict the list of values for each name and what the second request will return. Do not open its reference first.
4. Changed: Use `changed`. Predict the query and body separately. In a fresh copy, replace one form value with `a%2Bb` and predict again.
5. Teach-back: Explain why a plus sign in the raw request may mean either a space or a plus after decoding.
6. Later recall: next week, use a new attempt folder. Construct one GET and one form POST for a two-word value; explain every recorded field.

Label notes `first attempt`, `revised after evidence` or `later recall`.
These labels show the stage, not mastery. Save observations separately from
predictions, and ask a person to review the explanation and remaining limits.
