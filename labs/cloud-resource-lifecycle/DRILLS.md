# Practice sequence

Keep each first prediction. Use a new run folder for each attempt.

1. Mark the guided case's owners and dates. Work out what remains after the plan.
2. For each arrow, ask which item must be removed first. Does an expiry tag give permission to delete an item?
3. Predict the changed case before checking. On a new copy, write a removal order and explain your choice. Keep both sums of the units left.
4. Try the challenge case without references. Save a keep/review/remove checklist and the costs left before checking.
5. Teach how a budget alert differs from a control that enforces a spending limit.
6. A few days later, explain how an item could cost nothing but still remain. Add one such made-up item to a new copy and predict the result.
