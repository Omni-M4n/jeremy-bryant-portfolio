# Drills: TLS certificate review

## 1. Guided evidence pass

Prepare guided as `run/attempt-01`. Keep WORKED-EXAMPLE closed. Read the question and note the scope. Find the evidence, predict each decision and explain it. Use the word list if needed and record that help. Allow 30–45 minutes, or split the work into short sessions.

## 2. Fewer prompts

Work through these questions before opening the analysis:

- Which fixed time is being used, and why should the wall clock not change the answer?
- Does the requested host match any SAN?
- Which facts came from fields and which from a supplied chain report?

Check the decisions and read the worked example. Add one correction and cite the fact that changed your mind. If every label matched, explain your hardest choice. A lucky label does not show understanding.

## 3. Independent case

Prepare challenge in a fresh folder. Check each certificate against the given host name and time. Name the checks you can make and any trust questions still open. Save your decisions, evidence references and notes before opening analyse or any answer. The README can help with syntax and terms. Record that help. Then compare results and ask someone to review your reasoning. A case you have already read is repeat practice, not an unseen test.

## 4. Changed conditions

Prepare changed in a new folder. Compare its facts with guided and keep both attempts. Predict each result before opening analysis.

- Which host names match the listed names under the lab's wildcard rule? Show each comparison.
- Which time and chain checks pass, and which need attention? Cite the fields for each.
- Which checks would still be missing if all supplied fields passed?

Name each changed fact. Show how the same rules apply to the new facts. State what remains unknown. Keep the supplied case and reference files intact.

## 5. Teach-back

Explain expiry, name matching and trust as three checks. Show one wildcard match and one name it cannot cover. Cite a record ID. If you need the worked example, log that help and try later with it closed.

## 6. Later recall

Two days later, recall the date-boundary rule and the one-label wildcard rule. Try a new date and host name. Record what you knew without help, what you checked and one open question. This records practice, not full skill with real systems.

## Handover

Keep your worksheet and a short note. State what you saw, where the evidence is, what remains unknown and the next check. Include your first answer, corrections and help used. This lab requires no upload or public post.
